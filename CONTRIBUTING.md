# Contributing

Bugs, feature requests, translations: [file an issue](https://github.com/dsremo/Gallery/issues).

Pull requests are welcome. A few conventions:

- Keep the diff scoped — one theme per PR.
- No inline code comments; explain the *why* in the PR description instead.
- Preserve GPL license headers on files you touched from upstream. New files: an `SPDX-License-Identifier: GPL-3.0-or-later` header is enough.
- Build with `./gradlew assembleFossRelease` and verify the change on a real device before submitting.
